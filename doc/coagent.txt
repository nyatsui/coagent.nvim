1. INTRODUCTION                                          *coagent-intro*

coagent.nvim runs a multi-step coding agent (investigate, edit, run
checks, fix, report) inside terminal Neovim. Authentication and API access
are delegated to CopilotChat.nvim v4 (main branch); no Copilot CLI and no
extra API keys are used. See README.md and docs/manual.md for details.

Requirements: Neovim 0.11+, CopilotChat.nvim v4, plenary.nvim.
Check the setup with |:checkhealth| coagent.

==============================================================================
2. COMMANDS                                           *coagent-commands*

:Coagent [task]          Open the panel or send a task. With a range the
                              selection is attached (#selection).
                              ":Coagent /explain" runs a template.
:CoagentPrompt [name] [text]
                         Run a prompt template (|coagent-templates|).
                              With a range the selection is attached;
                              without a name pick one from a list.
:CoagentToggle           Toggle the panel.
:CoagentStop             Stop now (abort request, kill command, drop
                              pending approval).
:CoagentPause            Pause after the current step.
:CoagentResume           Resume a paused/interrupted/restored task.
:CoagentApprove[!]       Approve the pending action (! = always).
:CoagentDeny[!] [reason] Deny (! = deny and stop).
:CoagentReview           Review the pending edit hunk by hunk.
:CoagentChanges          List files changed by the agent.
:CoagentDiff             Diff of all agent changes.
:CoagentRevert [path|all] Revert agent changes.
:CoagentOutput           Show the last command output.
:CoagentMode [mode]      supervised | readonly | auto
:CoagentModel            Pick a tool-calling capable model (per role when roles are on).
:CoagentRoles [preset]   Model roles: single (default) | advisor | explorers | full
:CoagentNew              New session.
:CoagentSessions         Restore a saved session of this project.
:CoagentLayout [layout]  vertical | float

3. PANEL KEYS                                             *coagent-keys*

  a  approve          A  approve always     d  deny (with reason)
  D  deny and stop    r  review hunks       gd diff
  <Tab>/za details    <CR> open details     gf jump to change
  gc changes          ]] [[ next/prev item   <C-c> stop
  p  pause            R  resume             gs sessions
  gn new session      gm mode               i  input
  q  close            g? help

Input: <CR> (normal) / <C-s> (insert) send, <C-c> stop, <C-k> panel,
<C-p>/<C-n> history, /help slash commands (|coagent-slash|). All keys are
configurable via `keymaps`.

                                                     *coagent-references*
References in a prompt attach context:

  @path               A workspace file (same as #file:path). "@dir/"
                      attaches a directory listing. Only an "@" at the
                      start or after whitespace counts, and only when the
                      path exists, so a@b.com or "@Override" stay as typed.
                      The path stays in the prompt text.
  @buffer @selection  Aliases of #buffer / #selection (a file of that
                      name wins).
  #buffer #buffers    Current buffer / all listed buffers.
  #selection          Visual selection the command was started with.
  #file:path          A file.
  #diagnostics        LSP diagnostics of the current buffer.
  #gitdiff[:staged]   Uncommitted (or staged) diff.
  #url:https://...    A web page, fetched with GET and attached as text
                      (clipped to `references.url_max_bytes`, 32 KB).
  #clipboard          The + register (else the unnamed register), clipped
                      to `references.clipboard_max_bytes`.

#url fetches only URLs you type: no approval is asked because it is a
fetch, not a send. Only http:// and https:// are accepted; other schemes,
a missing scheme and credentials (user:pass@host) are refused. It reuses
CopilotChat's resources.get_url (lynx -dump, else curl -L with HTML
stripped) and adds no cookies or auth headers. The URL and size appear in
the timeline; the page is untrusted data like any attachment. Disable it
with `references = { url = false }`. The model has no web-fetch tool of its
own (a URL it chose could leak workspace data in its query string).
Typing "#" pops up the reference names.

Files outside the workspace (symlinks resolved) and protected files
(`auto.protected_globs`: .env, keys, .git, ...) are refused with a warning.
Typing "@" pops up workspace files (git ls-files plus untracked files that
are not ignored, else a directory walk; protected files hidden; at most
2000), fuzzy-filtered as you type. Disable the popup with
`ui.mention_complete = false` (<C-x><C-o> still works).

4. SLASH COMMANDS                                        *coagent-slash*

A prompt whose first word is /name runs a command locally; it is never sent
to the model. Typing "/" at the start of the input pops up the commands
(also <C-x><C-o>; disable the popup with `ui.slash_complete = false`).
Commands go into the input history like prompts.

  /compact            Elide every long tool output before the last 8
                      messages now. Local only: no request.
  /compact summary    Ask the current model ONCE to summarize the older
                      turns into one message (costs one request; <C-c>
                      cancels it).
  /new  /sessions  /model [role]  /mode [mode]  /roles [preset]
  /usage  /changes  /diff  /review  /stop  /processes
                      Same as the matching :Coagent* command.
  /clear              Clear the input.
  /help               List the commands in the timeline.

Unknown commands show an error and keep the text. Start with "//" to send a
literal "/" ("//help me" sends "/help me"). Text whose first word is not a
command name (e.g. "/etc/hosts is wrong") is sent as a normal prompt.

/compact is refused while the agent is working. The session history itself
is not changed; only what later requests send. Because the start of the
request changes, the next request is a one-time prompt-cache miss.

                                                     *coagent-templates*
Prompt templates run as /name [text] (or :CoagentPrompt name [text]). The
template text is put before yours, and #selection (started from visual
mode) or #buffer is attached unless your text names a source.

  /explain            Explain the code.                      (read-only)
  /codereview         Review the code for problems.          (read-only)
  /fix                Find, fix and verify the problem.
  /optimize           Improve performance and readability.
  /docs               Add documentation comments.
  /tests              Write tests and run them.
  /commit             Commit message for #gitdiff:staged.    (read-only)

/review stays the hunk review of a pending edit; /codereview is the code
review. A read-only template limits only its own task to read/search tools
(the bar shows "read-only (task)"); the mode returns afterwards. Templates
never raise the permission mode. Unknown names are not sent.

User templates come only from the config (never from repository files):
>lua
  prompts = {
    Summarize = { prompt = 'Summarize this code.', mode = 'readonly',
                  description = 'Short summary' },
    Tests = false,          -- remove a built-in
  }
<
Names are case-insensitive and become lower-case commands (/summarize).
`mode` accepts only 'readonly'. `context = false` skips the automatic
#selection/#buffer. A template named like a built-in command (/review)
is reachable only through :CoagentPrompt.

==============================================================================
5. MODES                                                 *coagent-modes*

readonly    Only read/search tools are offered and executed.
supervised  Reads run automatically; every edit and command asks first.
auto        Only for workspaces in `auto.workspaces` or explicitly enabled.
            Workspace edits and allowlisted simple commands run without
            approval (sandboxed when sandbox-exec/bwrap exists). Dangerous
            commands always ask.

6. LUA API                                                 *coagent-api*

  require('coagent').setup(opts)
  require('coagent').ask(prompt, { range = { l1, l2 } })
  require('coagent').open() / close() / toggle() / stop()

  require('coagent').controller()   -- events: controller.events:on(...)
  require('coagent').register_tool(tool)
